# AIRPAD 可用版本收尾 · 2026-09-12

基于 DeepSeek 推进后的现状继续，保留自动开启桌面控制、默认关闭实验手势和现有个性化阈值算法。

## 本轮交付

1. 将五阶段手型测量接入 GUI 校准入口，提供采集进度、重试、取消、明确保存和练习入口；采集原始几何分数，避免依赖待校准的分类阈值。
2. 修复当前回归：236 个测试中 235 通过，hand_check 报告缺失 next_step 字段。
3. 构建包含 Python、Qt、MediaPipe 和模型的 Windows 目录式 EXE，附双击启动入口；禁止包含用户配置、日志及相机画面。
4. 检查失帧、暂停、急停、模式切换的状态衔接；只对确认的问题做回归修复。
5. 运行完整测试、合成端到端回放、EXE 离屏启动和模型推理验证；更新真实交付说明。

## 约束

- 不覆盖用户配置，不自动开启实验手势，不更改系统鼠标设置。
- 校准和练习期间不发送桌面输入；相机原图和生物特征不写入交付包。
- 模型固定哈希，运行时本地处理；真实手势成功率必须由真人测量，合成测试不能代替。
- 工作区不是 Git 仓库；本轮源文件基线保存在 build/revision-baseline，用文件差异审查，不删除工作区。
- 已有真实输入测试工件作为历史证据，不通过替代路径绕过之前自动审批失败的真实注入测试。
