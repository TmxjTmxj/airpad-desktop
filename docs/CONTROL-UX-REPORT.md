# AIRPAD 操控体验交付 · 2026-09-27

用户已确认手部识别正常。本轮在既有个人校准之上优化操控，不修改识别算法或用户配置文件。

## 操作变化

- 捏合点击锁住指针位置。拖拽意图从食指位移改为固定起始掌尺度下的手掌位移，避免弯曲食指被算作拖动。
- 释放那一帧的手指回弹不再取消已确认的点击。
- 起拖需要连续接触确认、至少 180 ms 的捏合保持，以及足够手掌移动。Settings 可调整保持时间和起拖距离。
- 保留正常长拖拽；丢失后旧捏合必须先松开，才能接受新动作。
- 可选触控板预设开启两指滚动、关闭缩放和三指实验动作，保留所有个人识别阈值。
- 两指短停（120–400 ms）后收回单指为一次右键。明显移动后锁定滚动，退出不补右键。开掌、丢失、未知姿势和超时不会触发右键。
- 滚动以手掌平移为依据，避免收中指时的指尖变化误触滚动；保留模式进入后已积累的有效位移。
- 练习区显示左键、右键菜单与二维滚动反馈；在目标上起拖可以抓住目标并放到新位置，目标外起拖不会途中误抓。
- 桌面输入进程可以直接从两指模式启动，不必先进入单指跟踪；急停只能由显式 Enable 重新授权。

## 手感边界

合成测试证明动作链路和取消规则，不证明真人点击命中率或疲劳。两指短停窗口、180 ms 起拖和起拖距离仍是可调工程初值。请先在练习区使用，再切换桌面。`Ctrl+Alt+Space` 全局急停保持有效。

## 可复用经验

手指为了完成手势而改变形状，与手掌为了操作而平移，应分开计算。意图判定的起始尺度应固定，否则前后距离变化会改变同一动作的分类。释放帧不应反过来重写已确认的点击意图。

这些经验适合记录为长期调试知识。本轮仅写入项目报告；Obsidian vault 在授权写入目录之外，未改写。
